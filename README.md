# Run Command — Stream Deck Plugin

A [Stream Deck](https://www.elgato.com/stream-deck) plugin that executes command-line commands in **CMD** or **PowerShell** when a button is pressed.

## Features

- Run any shell command with a single button press
- Choose between **CMD** and **PowerShell** as the execution shell
- Load a **PowerShell profile script** before running the command
- Set a custom **label** displayed on the button
- Visual feedback on success or error

## Requirements

- Windows 10 or later
- Stream Deck app 6.9 or later
- Node.js 20

## Installation

Download the latest `.streamDeckPlugin` file from the [Releases](../../releases) page and double-click it to install.

## Usage

1. Drag the **Run Command** action onto a Stream Deck button.
2. In the property inspector (right panel in the Stream Deck app), configure:
   - **Shell** — `CMD` (default) or `PowerShell`
   - **Profile** *(PowerShell only)* — path to a `.ps1` profile script to source before running the command
   - **Command** — the command to execute (e.g. `echo Hello World`)
3. Press the button — the command runs in the background and the button flashes to indicate success or error.

## Development

### Prerequisites

```bash
npm install -g @elgato/cli
npm install
```

### Scripts

| Command | Description |
|---|---|
| `npm run build` | Production build (minified, no sourcemaps) |
| `npm run watch` | Watch mode with sourcemaps; auto-restarts the plugin on changes |

### Project Structure

```
src/
  plugin.ts              # Entry point — registers actions and connects to Stream Deck
  actions/
    run-command.ts       # RunCommand action — handles key events and spawns processes
dev.frik.run-command.sdPlugin/
  manifest.json          # Plugin manifest (UUID, version, OS requirements)
  bin/plugin.js          # Compiled bundle (git-ignored, generated by build)
  ui/
    run-command.html     # Property inspector UI (settings panel)
  imgs/                  # Plugin and action icons
```

### Debugging

Use `npm run watch` to keep the plugin running, then attach the VS Code debugger via the launch config in `.vscode/launch.json`. Source maps are included in watch mode so breakpoints work on the original TypeScript files.

## Release

Releases are automated via GitHub Actions. Push a tag to trigger a build and publish:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The workflow compiles the plugin, updates `manifest.json` with the tag version, packages it with `@elgato/cli`, and attaches the `.streamDeckPlugin` file to a GitHub Release.
